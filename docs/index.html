Palazzetti memory atlas

Interactive, read-only RAM and EEPROM maps for Micronova controllers, including the Palazzetti Ecofire Lara. Browse structures and fields alphabetically or by category; hover to highlight their bytes, click to select details and evidence.

Details distinguish our observations from external references, and address evidence from encoding or layout hints. Unlocated service settings appear in the list without highlighting guessed addresses. Other-board profiles are comparison material, not Lara maps.

These pages contain derived mapping facts, not private memory dumps. Layout cells show address offsets, with category backgrounds and evidence borders; they are not measured byte values. Unmapped cells are muted. With a private capture, hex values replace the offsets and a dot marks missing valid data. Reported and hypothetical meanings are not verified manufacturer settings. Fumis boards use a different protocol.

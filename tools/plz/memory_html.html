__TITLE__

Read-only Micronova memory atlas. Browse fields alphabetically or by category. Hover or focus previews a region; only clicking a field or byte (or pressing Enter) populates details. White outline: selected. Gold inset: hovered. Escape clears selection. Multi-byte regions and their members are linked across all three panels.

Layout cells show address offsets, not memory values. Category backgrounds identify mapped regions; bottom borders show evidence certainty. Unmapped cells are muted. In capture-value mode, a dot means no valid observation, never zero. Values are each address's last valid read, not a simultaneous snapshot. Generic profiles are not Lara maps.
